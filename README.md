## এই প্রজেক্টে যা যা শেখা ও ব্যবহার করা হয়েছে

এই প্রজেক্টটি তৈরি করার সময় নিচের বিষয়গুলো শেখা এবং বাস্তবে প্রয়োগ করা হয়েছে:

- **Next.js ইনস্টলেশন ও প্রাথমিক সেটআপ**
- **Routing এবং Route-এর মধ্যে Component ব্যবহার**
- **Dynamic Routing** ব্যবহার করে Dynamic Page তৈরি
- **Context API** ব্যবহার করে Global State Management
- **Toast Notification** ব্যবহার করে User Feedback প্রদান
- **Sorting** ফিচার ইমপ্লিমেন্ট করা
